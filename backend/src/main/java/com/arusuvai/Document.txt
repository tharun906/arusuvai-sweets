Chapter 11

Responsibility of Each Class

A table documenting every major class:

Class	Responsibility
CheckoutController	Exposes checkout summary API
CheckoutService	Converts calculation results into checkout DTOs
OrderCalculationService	Core business logic: validation, pricing, totals
OrderService	Creates and persists orders and order items
PaymentService	Integrates with Razorpay and verifies payments
OrderRepository	Persists OrderEntity
OrderItemRepository	Persists OrderItemEntity
CustomerRepository	Retrieves customer information
ProductRepository	Retrieves product and stock information
